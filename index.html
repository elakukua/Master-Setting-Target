Import submissions

Select the submission block in Excel (without the header row), copy, and paste below. Tab-separated, 16 columns, in this order — the same order as tblMaster §2.1:

Zonal ⇥ AP ⇥ AP_ID ⇥ Outcome ⇥ Code ⇥ Indicator ⇥ Num_Base ⇥ Den_Base ⇥ Pct_Base ⇥ Num_LOP ⇥ Den_LOP ⇥ Pct_LOP ⇥ Delta ⇥ AP_Proposal ⇥ Threshold ⇥ AP_vs_Threshold

Proportions may be written as 0.235 or 23.5% — both are read as 23.5%. An empty cell stays empty; it is never read as zero. Text is trimmed and cleaned. An AP that is not yet on the register is added to it automatically with all five outcomes on.

Import replaces the data and clears the decision log. Export the log first if you need it.
